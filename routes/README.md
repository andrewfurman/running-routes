# Running route research

This folder contains dated route plans, street geometry, GPX files, map previews, coverage audits and supporting evidence. `current-plan.json` selects the active snapshot, which is applied to the running visualization with `python3 scripts/planning/build_map.py`.

These records include running GPS tracks and dated street destinations. Some historical documents refer to the former Family Newspaper layout or private archive; private calendar exports, bike history and the original all-sport archive remain in Family Newspaper and are not published here. GPS proximity is evidence of a recorded path, not proof of CityStrides completion.
